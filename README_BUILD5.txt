BGB 360 Evaluation Build 5

1. Backup current application and MySQL database.
2. Copy bgb360 files into your existing C:/wamp64/www/bgb360 directory.
3. Preserve includes/config.php from your working installation.
4. No database import needed for Build 5.
5. Open /bgb360/management/consolidated.php as admin.
6. Choose modules and weights adding to 100%, then Save.
7. Use filters, export CSV or Print/Save PDF.

Teachers with missing results for any selected module are excluded from rankings, not given zero.
Results are restricted to admin/management roles.
