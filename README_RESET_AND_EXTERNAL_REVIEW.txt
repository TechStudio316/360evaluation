BGB 360 - RESET AND EXTERNAL REVIEW

1. Back up your live files and database.
2. Import database/UPGRADE_RESET_AND_EXTERNAL_REVIEW.sql into the existing database (do NOT re-import the full dump).
3. Upload application files, keeping your live includes/config.php unchanged.
4. In Management > Confidential Results, admins can reset/delete submitted evaluations or create expiring external assessor links.
5. Reset keeps the assignment and changes its status to pending. Delete removes the assignment. Both archive original data and revoke external links.
6. External assessor links are 7-day, random, single-assessment URLs; anyone with the link can view the shared assessment and submit one remark. Revoke them when no longer needed.
7. Reports must be saved as PDF by an administrator BEFORE reset/delete. Confirmation does not technically prove download.
8. The external remarks are available to management in Confidential Results, but do not change the numerical score.
9. Protect database backups and archived evaluations as confidential staff records.
